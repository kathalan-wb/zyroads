7. SCROLL EXPERIENCE

This is extremely important.

The website should have an immersive scroll experience inspired by modern high-end creative agency websites.

Do NOT simply use basic fade-in animations everywhere.

Use a combination of:

Scroll-driven parallax

Transform animations

Opacity transitions

Staggered text reveals

Scale transitions

Large typography movement

Background glow movement

Horizontal movement where appropriate

Subtle rotation

Section reveal animations

Hover micro-interactions

The animations should feel smooth and expensive.

Avoid excessive bouncing.

Avoid cartoon-style animations.

Avoid fast transitions.

Use smooth cubic-bezier easing.

8. HERO SCROLL PARALLAX

When the user scrolls:

Large outlined Z moves at a slower speed than the page

Green background glow moves subtly

Secondary glow moves in the opposite direction

Hero content gradually moves upward

Decorative elements create depth

Use requestAnimationFrame for scroll animations.

Do not attach heavy calculations directly to every scroll event.

Respect:

@media (prefers-reduced-motion: reduce)
